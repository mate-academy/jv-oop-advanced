Задача:
Имеются фигуры следующих типов: квадрат, прямоугольник, прямоугольный треугольник,
круг, равнобедренная трапеция.

Необходимо создать для них соответствующие
классы (Square квадрат, Rectangle прямоугольник, RightTriangle прямоугольный треугольник,
Circle круг, IsoscelesTrapezoid равнобедренная трапеция).

Все фигуры имеют:

состояние — все фигуры имеют цвет, но каждый тип фигуры может также иметь
одно или несколько уникальных свойств (радиус для круга, первый и второй
катеты для прямоугольного треугольника и т. д.).

поведение — мы можем получить площадь любой фигуры и нарисовать её.
«Рисовать» означает вывести всю информацию о фигуре с помощью
System.out.println() (не следует переопределять метод toString() для этого).

Подумайте, где следует объявлять эти поля и методы: в
классе/интерфейсе верхнего уровня / в классах нижнего уровня.

В методе main() необходимо создать массив фигур
(размер массива может быть 3 или 6, это не имеет значения).
Первая половина фигур в этом массиве должна генерироваться со случайными параметрами.

Для этого создайте ещё два класса:

ColorSupplier с открытым методом String getRandomColor() — для генерации случайного цвета,
и FigureSupplier с открытым методом Figure getRandomFigure() — для генерации фигур со случайными свойствами.
Другая половина фигур должна иметь те же параметры по умолчанию.

Для этого создайте новый метод в классе FigureSupplier:

public Figure getDefaultFigure() — этот метод должен всегда возвращать белый круг радиусом 10.
